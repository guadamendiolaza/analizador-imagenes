🚀 Guía: Cómo Publicar Gratis en GitHub Pages

Esta aplicación está construida de manera 100% estática. No necesita servidores, bases de datos ni compras de dominio. Puedes alojarla gratis en GitHub con tu enlace personal https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/.

Paso 1: Crear una cuenta y repositorio

Entra en GitHub.com (gratis) y crea un nuevo repositorio público, por ejemplo llamado analizador-documentos.

Paso 2: Subir los archivos del proyecto

Sube todos los archivos de esta carpeta (index.html, styles.css, la carpeta js/, etc.) arrastrándolos directamente en la página web de GitHub o con el comando git:

git add . && git commit -m "Publicar aplicación" && git push origin main
Paso 3: Activar GitHub Pages

En tu repositorio en GitHub, ve a la pestaña Settings (Configuración) → menú lateral Pages. En la sección Build and deployment, elige:

  • Source: Deploy from a branch
  • Branch: main y carpeta / (root)
  • Haz clic en Save.
Paso 4: ¡Tu aplicación en vivo!

En aproximadamente 1 o 2 minutos, GitHub te dará tu dirección pública en verde:

https://TU-USUARIO.github.io/analizador-documentos/

Todas las rutas son relativas, por lo que funcionará de forma inmediata tanto en tu computadora como en GitHub Pages.
